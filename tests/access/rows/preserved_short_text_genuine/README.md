# Genuine preserved Short Text expectations

These tools independently derive fitting Short Text expectations from the exact
original file, its original readonly SDK observations and literal requests. They
start no fixture processes and never use a native producer output as model input.
The finite observed sources have a compact seven-byte `alpha` span and a zero-byte
NULL span, both without internal slack. They retain calculated caches, Memo/OLE,
attachments, indexes and Sentinel data.

`framing.py` retains the executed original-only raw-inspection function body.
`model.py` is byte-exact to the independently executed expected model. Both use
the existing maintained generic native framing helpers. `prepare.derive_cases`
is the maintained pure composition boundary: it qualifies explicit immutable
original bytes and yields one expected image/proof/reader projection at a time.
It performs no filesystem writes or private-controller imports. Historical
creation, authorization, build and execution programs remain pinned evidence
rather than programs this package executes.

The promotion changes orchestration and module location, not source requests,
payload choice or golden bytes. The nine successful cases per header include
shorter/equal-capacity Unicode, NULL/empty distinctions, representation-preserving
no-ops and NULL-to-present-empty through the selected mask only. Two overflow
controls per header produce no expected database or reader projection. Every
unselected rich raw span remains exact after any in-record relocation; record
lengths, row references, other records and all other pages remain unchanged.

The saved verifier uses `ArtifactStore` to rehash every saved artifact, independently
rederive images and compare complete native candidates, exact CLI reports and
whole readonly SDK inventories. Cached programs are data only; missing artifacts
are errors and never trigger downloads, compilation, artifact regeneration or
producer invocations. Recomputed bytes exist only in memory for comparison.
The recorded runs produced 18 complete-image candidate matches, four capacity refusals and
18 fresh readonly SDK inventory matches. The result record separately reports
the maintained saved-verifier outcome.

Run the saved verifier with the local recorded artifact tree:

```sh
python3 docs/testing/preserved_short_text_genuine/verify.py --root /path/to/TableCraft
```

These results concern explicit non-journalable engineering copies. They do not
qualify native Microsoft Access execution/save, macro absence or normal ACE saves.

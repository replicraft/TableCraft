# Shared evidence-tool orchestration

`git_objects.py` verifies a bounded optional Git-object protocol response under
its own standard-library and checkout-root bindings. Importing it executes no
Git process. `saved_cli.py` owns consistent argument/error/publication behavior;
feature callers explicitly bind their description, defaults and replay service.

Synthetic protocol/CLI regression evidence is distinct from actual Git, fixture,
JVM, database or Windows execution. Historical source pins remain strict.

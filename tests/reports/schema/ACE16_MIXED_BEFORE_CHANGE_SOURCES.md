# Mixed-schema BeforeChange sources

These repository-authored source images and literal expected outcomes precede
normal mixed-schema writer execution. They establish read and representation
facts; they grant no write permission or macro-absence certificate.

`tablecraft_testkit::access::canonical_mixed_before_change` reuses the owned
fixed/variable creation envelopes and Wide-MR2 encoder. Twenty-four originals
under header selectors 5 and 6 produce sixteen complete positive expectations.
The fixed profile retains all ten scalar declarations, including signed-zero
representations, and an unaligned Int32 target. Variable profiles retain Unicode,
Binary, exact Decimal, Boolean and NULL/present-empty distinctions while adding
an ordinary Score field. Counter profiles declare the actual readonly AutoNumber
Id; selected primary-index metadata, keys and counters remain unchanged.

Positive models cover sequential assignments, Old restoration, readonly counter
operands and empty requests. Refusal contexts have no modeled AFTER image:
generated user targets, dormant generated macro targets, non-Int32 operands and
a later RaiseError. Their intended refusal is not a passing normal-writer result.
Every positive expectation overlays only the literal eligible four-byte payload,
or preserves the entire original for restoration and empty operations. No
production writer, evaluator or observed writer output supplies expected bytes.

retain calculated caches, long-value storage and attachment associations. Two
header-6 expectations overlay only Large_Number's low four-byte Int32 carrier;
the upper padding and complete remaining image remain unchanged. Header-5
native-20 siblings retain the existing preserved-source refusal. These tests use
actual projected reads rather than manufacturing complete scalar rows for opaque
fields. The old complete-row logical preparation API remains strict.

The ordinary native gate passes all forty views through complete scalar reads,

passes four admitted views and two expected source refusals. Separate exclusive
exports retain all forty-six complete images before normal writer execution.

# Mixed external edits and wider primary-prefix sources

Two independently constructed source families now pass native read checks and
complete inert Jackcess reports before their matching normal writers.

| Family | Unique files | Native selected contexts | Independent reader reports |
| --- | --- | --- | --- |
| Mixed external Memo/OLE retirement with reuse, growth or shrinking | 20 | 20 | 20 |
| Two-row wider secondary promotion with primary-prefix growth | 6 | 8 | 6 |

Mixed long-value views cover four recipes in both request orders across four
original profiles: clear Blob while growing Memo on another parent, clear Memo
while reusing Blob on the same parent, clear Blob while growing Memo with a moved
descriptor, and clear Memo while shrinking Blob. Thirty-two request contexts
share sixteen changed images. Original chain references, payload residuals,
parent capacity, retired prefixes and actual allocation-map roles remain exact.
The testkit owns the reusable literal views; native assertions remain beside
the engine source checks.

The prefix family adds two ordered complete rows to original 400-row tables.
The primary requires a three-byte common prefix; both wider secondary roots
promote and allocate four represented INDEX pages. DATA uses existing owned
capacity. The descending parent and right leaf can legitimately equal their
single-row predecessors; equal bytes are not a stale-source refusal witness.

Frozen request/allocation laws preceded Python construction. Separate Rust
source tests replay complete expected images without calling mutation planners,
then capture actual Source, index aliases, histories, memberships and constraints.
The independent reader controllers passed all 26 exact reports on their first
attempts. Closed saved verifiers retain input/output hashes and reject modified
receipts without starting children. These phases do not qualify native Microsoft
Access saves or grant write permission.

`TABLECRAFT_WIDE_PRIMARY_PREFIX_SOURCE_DIR` to the relevant absolute fixture
directory and run the selector with `cargo test -p tablecraft-ace --all-features
--lib SELECTOR -- --ignored`.

and ten literal expected images under header selectors 5 and 6. It consumes only

Each original changes row one's Int32Value to 10 while row zero remains zero.
`WHERE Int32Value=0` therefore selects only row zero. The five recipes cover
Boolean true, Int64 -101, Currency scaled -10001, legacy DATE 1.25 and an atomic
joint assignment. The stored program independently implies macro-only row-zero

The joint SQL sets Flag true and assigns Int64Value from
`CLngLng(IIf([Flag],7,42))`. Every RHS reads the original false Flag, so the
literal outcome is 42 in either SET order. Date 1.25 is the exact representation
of 1899-12-31 06:00:00 in this source profile. The SQL uses already admitted
mutation functions and a date literal; no builtin availability is inferred from
this fixture. Signed-zero and alias DATE cases remain separate typed witnesses.

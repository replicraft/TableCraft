# Ordinary indexed Int32 target sources

`canonical_ordinary_indexed_targets` authors original requests and complete
literal outcomes from the qualified [ordinary indexed originals](ACE16_ORDINARY_INDEXED_SOURCES.md).
It consumes their BEFORE bytes only. Sixteen recipes across header selectors 5/6
provide 32 originals and 24 positive AFTER views. Requests target `Items.Id`;
positive outcomes use manual fields, and empty requests retain one empty group.

Positive outcomes cover Id 1→7, NULL promotion/clearing, an untouched NULL
neighbour and its inactive payload, an atomic UNIQUE swap, two stored all-NULL
UNIQUE entries, compatible logical aliases, a two-leaf tree, fitting prefix loss
from 4 to 1, and exact empty/present/NULL noops. NULL keys retain their original ROW
suffixes. Clearing a value retains its inactive payload. Literal outcomes preserve
all bytes outside the declared Id payload/mask and index framing/active-stream
changes, including original index tails, counters/history, aliases, maps and EOF.
The all-NULL UNIQUE case is a format/read observation, not Microsoft Access write
conformance.

Two original shapes are explicit derivatives: the tree's Id flags change 7→3 and
LAST resets to zero to declare a manual field, while the alias leaf stores its
original keys using prefix 4. Neither removes a stored program or derives write
permission from construction. Both originals require the same source-read checks
as every literal outcome.

Four request contexts per header have healthy BEFORE images and no AFTER:
UNIQUE collision, stale expected Int32 against an actual NULL cell, generated Id
assignment, and NULL assignment to a primary index key. They record intended
future planner refusals; the source-read test does not execute those requests.

The native read-only gate passes all 32 originals and 24 literal outcomes through
actual table/index checks, scalar reads and constraints. The explicit exclusive
exporter passes and saves 56 image/report pairs plus original request metadata.
Expected reports reuse the established source formatter; cursor order comes
from literal optional Int32 cells and original row suffixes. No writer or SDK
observation supplies expected bytes.

All 56 independent SDK calls pass with exact reports and empty stderr. Saved
verification checks call identity/arguments, complete expected output and unchanged
source/JAR/class pins. The observer and compiled class closure are reused unchanged
from the preceding ordinary-indexed source phase; no indexed producer runs.
Source qualification remains
separate from content admission, indexed mutation, journal/recovery and shared
session acceptance. No allocation, generated-field update permission, native
Microsoft Access or Windows qualification is established here. See the
[source result](../../results/indexes/ace16-ordinary-indexed-target-sources-2026-10-31.json).

# NODE child-retirement source qualification

Eight views pass native read/source checks and 48 exact read-only SDK observations
before matching normal retirement producers run. Two original 800-row sources
have six independently modeled AFTERs covering left-child retirement,
right-child retirement and deletion of all rows.

A sole-child NODE keeps one bounded child entry with zero tail; this source family
does not promote its nonempty child into the root. Fully empty roots become leaf
pages. Retired pages gain invalid headers while retaining residual bodies.
INDEX-owned/global-free claims change exactly; original DATA payloads, free/slot
counts, candidate maps, historical counters and EOF remain preserved.

The native gate reconstructs all complete images and checks every row, physical
reference, logical index alias, root form, map complement, constraint and full
Source/NoRequired admission. Saved verification checks the SDK reports and frozen
pins without starting a reader or writer.

The [source record](../../results/indexes/ace16-node-retirement-sources-2026-11-01.json)
separates these observations from future mutation acceptance. Native Access
save/reopen and Windows qualification remain unrun.

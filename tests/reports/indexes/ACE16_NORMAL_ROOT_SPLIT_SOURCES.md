# Normal root-split source qualification

Two genuine fitted originals and two existing independent model images now pass
current native metadata, Required=true, constraint, complete index and full
Source/NoRequired checks. The gate reconstructs complete raw effects without
calling mutation or preview code. The [execution record](../../results/indexes/ace16-normal-root-split-sources-2026-11-01.json)
binds the unchanged original/model files, historical reference evidence and the
additive provenance closure. Historical SDK calls were not rerun for this gate.

Both originals have a native17 catalog, manual Int32 primary keys, a nullable
Binary sibling and 451 entries sharing a one-byte prefix. Inserting ID226 and an
empty Binary value fits original DATA capacity but requires two new INDEX leaves
and root promotion. The source GLOBAL bits are explicitly free and the future
index-owned bits clear; the model claims those exact two pages. This establishes
no authority rule for zero or unrepresented EOF cells.

Readable prefix1 sources do not bypass the existing normal fitting planner's
prefix0 limit. Normal split planning, allocation proof, recovery and host saves
still need separate implementation/acceptance. No native Access save/reopen claim
is made. Private source artifacts are not CI inputs.

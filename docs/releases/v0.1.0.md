# TableCraft v0.1.0

Release notes in preparation. No v0.1.0 tag or release has been published.

## Included functionality

- Inspect local MDB/ACCDB files, list tables and row counts, and browse records.
- Browse tables, inspect fields and run the documented Access SQL query profile
  in the shared desktop workspace or CLI.
- Create a blank ACE 16 ACCDB and use the supported reviewed row/schema editing
  workflows, with explicit refusal outside their qualified native profiles.
- Retrieve complete multivalue lists or explicitly expand their `.Value` members.
- Read qualified password-protected databases and create fresh encryption-management copies.
- Select table or TSV output, saved queries and explicitly mapped linked/external databases.
- Use light/dark themes, sectioned Fluent translations and shared regional
  display preferences in the desktop preview.
- Check for publisher-signed desktop updates through the About controls.

ACE 16 is the primary compatibility target, with working bounded profiles for
Jet 4 and ACE 2007 alongside it. This release does not claim complete native
Microsoft Access compatibility. General editing of arbitrary imported databases,
live shared-file editing, forms/report designers and VBA execution remain
unfinished or deferred. Native installer/update qualification is still in
progress; these notes are not a passing release receipt. See the
[compatibility matrix](https://github.com/replicraft/TableCraft/blob/v0.1.0/docs/COMPATIBILITY.md)
and [CLI guide](https://github.com/replicraft/TableCraft/blob/v0.1.0/docs/cli/CLI.md).

## Downloads

The planned release set covers x64 and ARM64 on each platform:

| Platform | Desktop | CLI |
| --- | --- | --- |
| Windows | MSI installer or portable ZIP | ZIP |
| macOS | Custom DMG or portable app-bundle ZIP | TAR.GZ |
| Linux | DEB, RPM, AppImage or portable TAR.GZ | TAR.GZ |

Desktop filenames start with `tablecraft-desktop-0.1.0-`; CLI filenames start
with `tablecraft-cli-0.1.0-`, followed by the platform and architecture.
For the CLI, extract the archive,
put `tablecraft` (`tablecraft.exe` on Windows) on your `PATH`, and run
`tablecraft --help`. Rust and Microsoft Access are not required to run the CLI.

Each package has a SHA-256 sidecar and a Minisign signature. Separate CLI/desktop
checksum manifests and generated third-party notices accompany the downloads;
packages also include their own notices and the project license. Publisher
signatures authenticate downloads. Windows packages are not Authenticode-signed,
and macOS packages are not Developer ID signed or notarized. DEB/RPM updates stay
with the package manager. Platform installation details are in the
[release guide](https://github.com/replicraft/TableCraft/blob/v0.1.0/docs/development/RELEASING.md).

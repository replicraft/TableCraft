# TableCraft v0.1.0

First public release of the TableCraft command-line application.

## Available now

- Inspect local MDB/ACCDB files, list tables and row counts, and browse records.
- Run the documented Access SQL query profile over local databases and read-only SQLite sources.
- Retrieve complete multivalue lists or explicitly expand their `.Value` members.
- Read qualified password-protected databases and create fresh encryption-management copies.
- Select table or TSV output, saved queries and explicitly mapped linked/external databases.

ACE 16 is the primary compatibility target, with working bounded profiles for
Jet 4 and ACE 2007 alongside it. This release does not claim complete native
Microsoft Access compatibility. General database editing, the desktop UI and VBA
execution are not part of this release. See the
[compatibility matrix](https://github.com/replicraft/TableCraft/blob/v0.1.0/docs/COMPATIBILITY.md)
and [CLI guide](https://github.com/replicraft/TableCraft/blob/v0.1.0/docs/CLI.md).

## Downloads

Choose the archive for your operating system and processor:

| Platform | Archives |
| --- | --- |
| Windows | `windows-x64.zip`, `windows-arm64.zip` |
| macOS | `macos-x64.tar.gz`, `macos-arm64.tar.gz` |
| Linux | `linux-x64.tar.gz`, `linux-arm64.tar.gz` |

Each archive name starts with `tablecraft-cli-0.1.0-`. Extract the archive,
put `tablecraft` (`tablecraft.exe` on Windows) on your `PATH`, and run
`tablecraft --help`. Rust and Microsoft Access are not required to run the CLI.

Checksum sidecars, `ThirdPartyLicenses.txt` and `SHA256SUMS.txt` accompany the
archives. The fourteen-asset set contains six archives, six sidecars, the shared
license text and the complete checksum manifest. Each archive includes the project
license and `ThirdPartyLicenses.txt`. macOS binaries are not Developer ID
signed or notarized; platform installation details are in the
[release guide](https://github.com/replicraft/TableCraft/blob/v0.1.0/docs/RELEASING.md).

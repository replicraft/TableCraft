# Source/request whole-image constructor

This constructor is a separate expected-image owner. It consumes both immutable
qualified original images and their raw metadata/values, plus exactly one
explicit Parents.ID 1 delete seed per original. It reads no public AFTER, Java
delete output, producer archive/build or native candidate. It must be frozen and
reviewed before its first actual derivation.

Original associations determine the cascade closure and surviving SET NULL
assignments. The model does not find matches against already edited values.
Only mixed CascadeChildren 20 joins the parent deletion. Children 10 and 11
survive with their original ParentID fixed payload retained and only their
presence bit cleared. Existing NULL/nonmatching children, markers, Sentinel and
all unrelated source bytes remain unchanged.

Deleted original logical roots receive the ordinary 0xc000 tombstone flags and
only their table live counts decrement. Record bodies and DATA free space do not
change. No DATA, INDEX or bitmap allocation/retirement occurs. This fitted corpus
retains at least two entries in each changed leaf and does not qualify empty-root
retirement, internal-node movement or a wider multi-call reference transaction.

Each affected physical index is handled once despite logical aliases. New
streams are independently encoded as nullable ASC Int32 key-only bytes plus
original logical ROW, sorted by key then ROW. Required and Ignore NULL rules
apply to surviving tuples. Leaf framing keeps the original prefix seed up to the
new key-only common prefix, increasing compression only if ordinary capacity
would require it. The complete original page is retained outside free/prefix,
entry-boundary bitmap and newly active wire spans; inactive wire residue is not
zero-filled. Unchanged streams remain byte exact. Historical counters remain
unchanged for deletion and key replacement. Maps, definitions except live-count
fields, relationships and file length remain exact.

The preparation controller must requalify BOTH original sources before creating
any output directory, then recheck every frozen input before first derivation.
It records the input barrier, derives both images, and verifies the full closure
again before freezing outputs. A failing first pure attempt must be retained;
expected bytes may not be repaired from public AFTER or producer behavior.

# Genuine preserved Short Text growth evidence

`model.py` is an unchanged copy of the independently executed original/request
model. It rebuilds the selected record from original spans, retains opaque
siblings and creates same-page hidden records with stable logical roots.
`prepare.py` exposes that model as a pure iterator. Neither imports programs from
the private artifact cache or invokes a database writer.

The finite corpus contains two immutable originals and eight cases: four SQL
single-row updates and four typed batches, including reversed request order.
Every batch places records in original source order. Original-only framing is
shared with `preserved_int32_genuine`; expected forwarded records use the new
model's bounded forwarding checks.

The expected images were independently constructed and admitted as complete
sources before candidate production. All eight native candidates matched those
images on the first run. Eight fresh SDK readbacks also matched the complete
independent inventories on their first run, preserving original logical row IDs.
The saved verifier reads recorded artifacts without launching processes and
checks archive file membership, metadata and Git blob identities. This evidence grants
no normal ACE save, journal, data-macro or native Access compatibility authority.

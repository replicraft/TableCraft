The separately qualified unmodified public V2016 original has 96 pages, Items
definition89, empty primary root91, zero ordinary-owned members, zero primary
history and an existing69-byte indirect owned record with a zero first pointer.
No public AFTER, engineering candidate or new producer build is an input.

Each candidate begins independently from this same source. The single request
uses ID7/Binary8000ff; the batch uses sixteen IDs100..115 with255 e7 bytes each.
Every record uses the actual C2/V1 declaration with a six-byte fixed extent,
reverse variable offsets/count and one mask. Every Binary is explicitly present.
No defaults, empty-Text policies, AutoNumber or new scalar carrier are involved.

Allocation derives from actual sourceEOF and empty hints. First DATA96 precedes
owned bitmap97. The short case ends at98pages. The batch fits fifteen268-byte

The complete original owned reference record is copied and only pointerzero is
replaced. Higher pointers and all existing metadata bytes remain protected. The
owned bitmap contains DATA members only; candidate contains the last DATA page.
The fitted primary keeps its original page/seed/residue policy and receives
independently encoded Int32+logicalROW entries. Both logical aliases share one
physical counter increase, fromzero to1or16. Table counts match newrows.

roles, verifies source-prefix allowed spans and preserves every unrelated source
byte, Sentinel record and any unclaimed allocation. It never finds a destination
by scanning physically occupied pages outside ordinary ownership. The frozen
source/helper/catalog proof supplies immutable source facts only, never staged
producer placement or map bytes. Public reference framing/unused-byte behavior
will be measured later; complete public/engineering equality is not presumed.

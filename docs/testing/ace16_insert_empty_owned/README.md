# First INSERT on an original empty ordinary table

Two engineering candidates on one immutable public-created ACE 2016 original
match complete SOURCE/request-derived images. Two fresh combined row/map reads
then pass. A separate public reference phase passes four child calls and two
transition proofs; both public files also match the earlier images byte for byte.
These runtime phases pass first attempt. Preparation stops described below remain
separate; this is not Microsoft Access execution or native save qualification.

The repository-authored [helper](EmptyOwnedInsertFixture.java) uses the already
reviewed Jackcess 5.0.4 JAR to create empty Items with required manual Int32 ID,
nullable Binary255 Bytes, one primary physical index and two logical aliases.
Sentinel contains (91,12345). No source patch, deletion, orphan construction,
count search or adaptive regeneration is used. V2016 is the primary ACE 16 target;
a duplicate V2019 recipe is not inferred as additional original-file evidence.

The actual original has 96 pages, definition 89 and empty primary root 91. The
existing ordinary-owned record is 69-byte REFERENCE storage with missing pointer
zero and no DATA members; candidate storage is empty. One saved gate binds zero
logical membership/history, complete raw metadata, aliases, properties, catalog
map roles and Sentinel before any constructor runs.

The batch places fifteen rows at 96:0..14 and the last at 98:0. Bitmap 97 is reused;
it is never a DATA member or candidate. The original map record keeps all higher
pointer bytes, the primary remains fitted at 91, and aliases share one historical
counter. Global allocation changes only represented cells. Sentinel/system
metadata, unrelated bytes and any unclaimed allocation stay protected. This
public source does not manufacture the nonzero higher pointers or occupied
unclaimed pages exercised by the separate literal regression controls.

filename guard excludes this slice's constructor/expected/build/native inputs
while retaining the existing raw-read owner. No reference child or proof ran
during that stop. Both earlier checkpoints remain retained.

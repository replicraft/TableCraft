# Normal BeforeChange source corpus

This source-only tranche qualifies independently authored readable bytes before
normal ACE mutation is exercised. It does not establish write admission, macro
absence, native event timing or Access save behavior.

The single fixture owner, `tablecraft_testkit::access::canonical_before_change`,
reuses the qualified complete canonical envelope and independent Wide MR2 encoder.
Sixteen recipes under each header selector 5 and 6 provide 32 originals. Fourteen
complete modeled after-images are frozen separately. Every image is 36,864 bytes,
with one manual, unindexed Int32 `Items(Id, Score)` table and three rows:
`[1,10]`, `[2,20]`, `[3,30]`. The actual catalog row 4:7/native ID 7 owns the
original MR2 Extra; body/module presence, name-only or unresolved definitions
remain explicit facts. No imported template or producer output supplies an
expected image.

Seven recipes per header have literal modeled outcomes: sequential Current/Old
assignments produce Score 28; a macro-only target produces Id 11/Score 17;
a supplied equal assignment plus increment models Score 11; restoring Old
returns the original image; empty requests and a complete no-op remain unchanged;
and active increment with a dormant Delete guard models Score 18. Nine further
recipes retain no modeled candidate, covering late RaiseError, after/named
programs, incomplete carriers, opaque action, body content, stale expectations
and duplicate ordinals.

These outcomes do not grant normal execution permission. Initial normal scope
refuses both `UserNoopMacroChanges` and `AllNoop`: supplied equal assignments have
unqualified native timing. Their four modeled after-images stay in the corpus.
Zero supplied requests are distinct. `RestoreOriginal` retains its original
10→17 user request even though the modeled final image equals its input.
Every other context still needs independent normal admission and validation.

The native read-only gate passed all 32 original and 14 modeled views through
ordinary table/constraint inspection, exact rows/schema, retained Extra/body
coverage, GLOBAL and full map metadata. The explicit create-exclusive export
produced 46 images plus inventory and original-request manifests. Ordinary hash
anchors passed two functions, with the explicit exporter ignored during that
non-export run. The request manifest binds original ordinals and expected/user
replacement values; final macro values never replace those requests.

The unchanged read-only `CanonicalAceV2Getter` observed all 46 views on the first
attempt. All four metadata APIs, every system/user schema and row, raw catalog
Extra/body payloads, complete ordered stdout and empty stderr matched independent
expectations. Header 5 reports V2016 and header 6 V2019 under the pinned SDK's
format mapping. Expected rows are literal; a bounded original-input parser
supplies opaque catalog payload facts. No expected observation comes from SDK
output. Full source/class/input hashes remained unchanged. ACE/testkit strict
checks passed; final documentation/format checks are recorded separately.

There were no macro program, normal planner, native mutation writer or journal
calls. SDK row reads are independent-reader evidence, not native Access runtime
or Windows creation/save comparisons. The [source result](results/ace16-normal-before-change-sources-2026-10-31.json)
keeps these facts and the no-op admission boundary separate from future durable
normal-write acceptance.

# Existing Single/Double UPDATE source pairs

Six unchanged files from the prior wider-scalar INSERT study supply four exact
UPDATE before/after pairings across ACE header families 5 and 6. Each file retains
its prior independent-reader evidence; this audit constructs no new database and
runs no write producer or external reader.

The complete original declarations, three rows, raw records and Single/Double/DATE
bits pass. The exact-to-subnormal transition changes one row's Single and Double
payloads and changes its DATE negative zero to positive zero. The
subnormal-to-special transition changes only the same Single/Double payloads,
including their original NaN bits. Manually overlaying those literal byte spans
reconstructs each complete paired file; every other byte remains unchanged.

Actual `NoRequiredTablePrograms::capture_updates` and canonical ordinary Source
capture each admit all six states. These observations qualify original sources;
they do not establish mutable Single/Double targets, request encoding, journal
replay or native Access saves. Those services require separate implementation
and matching acceptance.

One ignored engine function and ACE all-target/all-feature strict checks pass. The
[execution record](results/ace16-ieee-update-sources-2026-11-03.json) retains the
command, source hashes and separate admission observations. Before execution,
review corrected a test-only digest formatting assumption to the existing
byte-wise hexadecimal pattern. The source files and byte laws stayed unchanged.
Native Access save/reopen and Windows mixed-client evidence remain unrun.

# Constant-default source qualification

Twenty-eight independent views pass native metadata, row, constraint and complete
Source/NoRequired checks before matching default creators run. Twenty-eight exact
read-only SDK reports and saved verification also pass. Receipt/summary/plan
tamper controls are recorded separately from those observations.

Eight BEFORE and twenty literal AFTER views cover Boolean, Int64 boundaries,
exact scaled Currency, quoted Unicode Short Text and NULL defaults. Omission,
supplied NULL, supplied false and Text overrides stay distinct. Required/empty
refusals have no successful AFTER. Date, clocks, generated values and arbitrary
expressions remain separate work.

The source model uses independently authored native17 Empty inputs and raw
TD/MR2/record overlays. It calls no creator, default resolver or mutation planner.
The native gate independently checks whole-file complements, raw records,
properties/carriers and current source admission.

The [source record](results/ace16-constant-default-sources-2026-11-01.json)
retains frozen closures, SDK execution and the first native receipt. This does not
qualify a matching creator, native save or Microsoft Access behavior.

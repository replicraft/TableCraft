# Retained Int64 and Currency index updates

Normal fixed UPDATE can maintain qualified existing numeric NODE trees using the
same TCNI4 and checked V1 journal contract as fitting root leaves. The dense
schema contains exact Int32, Int64 and Currency carriers, with at least one wider
index. Original metadata selects the tree route before planning. Compound keys,
ignored-NULL indexes, new pages, splits and arbitrary schema combinations remain
separate work.

Complete ownership capture checks every descendant, alias, allocation map,
catalog member role and live LVAL exclusion. Wider INSERT/DELETE retain their
previous root-leaf restrictions. Physical rewriting preserves topology and each
original leaf's entry count, then derives full fences from the final sorted
key-plus-ROW population. This is an explicit fitting policy; it does not claim
byte identity with Jackcess's update placement or native Access saves.

Fresh proof independently binds original assignments and exact numeric carriers,
reconstructs DATA and signed keys with original ROW suffixes, and replays original
partitions, masks, free counts and fences. It does not take staged page choices
or keys as authority. UNIQUE checks use the complete final population. Histories,
maps, inactive tails, unrelated bytes and EOF remain protected.

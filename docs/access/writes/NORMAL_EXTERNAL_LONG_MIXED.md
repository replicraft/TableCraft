# Mixed external Memo/OLE updates

Normal fitted UPDATE composes whole-page retirement with qualified retained
payload reuse, terminal growth or shrinking in one original-image plan. Existing
TCNI5/V1, typed/SQL retained sessions and CLI services remain the public route.
No caller-supplied allocation or retirement flag grants permission.

Each original parent is rebuilt once across all assignments. A retained
descriptor is located again in that rebuilt frame; its original offset is not
reused after another field disappears. Actual original chains, capacity, live
LVAL ownership and map roles qualify before staging. Complete-page retirement
keeps its existing exclusion of unselected live slots, other owners and conflicting
roles. Retained links/references, retired residual bytes, unrelated orphan pages,
index bytes, histories and EOF remain protected. Changed-row counts use the union
of changed original parents, not the number of assignments.

Separate proof reconstructs the parent frame, moved descriptors, retained chains
and original retirement-map effects without producer patches or traced payloads.
It compares the complete candidate and captures fresh final Source. Mixed plans
do not retry the old reuse/growth or retirement-only planners after failure.

The [independent sources](../../../tests/reports/storage/ACE16_MIXED_EXTERNAL_PREFIX_SOURCES.md)
preceded matching writes. All 32 request-order contexts pass exact commits and
ordered result-relative no-ops. Eight named-column empty plans pass; four distinct
targetless requests correctly refuse the existing intent contract before native
planning. Independent proof, 480 recovery contexts, 128 committed-mixture refusals,
576 journal forgeries and measured public resource/cancellation controls pass.
Thirty-two typed and sixteen SQL saves retain leases, receipts, empty follow-ons
and stale-handle checks; sixteen CLI saves/readbacks pass.

SQL/CLI cover NULL and Text recipes, including eager-safe `IIf` expressions for
different original parents. Binary replacement remains typed coverage. These
checks invent no Binary SQL literal or implicit carrier conversion. See the
[execution record](../../../tests/results/storage/ace16-mixed-external-writes-2026-11-02.json).

Partial-page retirement, relocation, new external allocation and native Microsoft
Access save/reopen remain separate work. The portable and independent-reader
checks establish their stated profiles, not full native Access compatibility.

# Normal height-two Int32 retirement

Normal original-witness DELETE now retires qualified leaves and an exhausted
internal parent beneath a retained height-two root. Native intents, V1 recovery,
retained typed/SQL sessions and CLI commands use the same connected service.

The qualified original has an ascending, present Int32 tree with two bounded
root children and nonempty tail-form leaf parents. Root prefix is zero; parent
prefixes retain their validated seed, including the observed prefix 2. At least
one original row must survive. Retiring one leaf or an entire parent preserves
the original root identity and height. A nonempty child is never promoted.

The producer uses the existing contraction, page framing, retirement and leaf
link owners. Internal sibling collection/repair is shared with its actual preview
callers; preview-only audit state remains gated. The independent proof derives
original partitions, surviving maxima, fences, maps and all-level links afresh.
It preserves originally unlinked internal levels, writes the derived tail after
seed-relative framing and retains retired page bytes outside their first four
bytes. Original DATA bodies, capacity, historical counters and EOF remain exact.

Six independently modeled sources passed native and independent reader checks
before matching writes. Eight native commits, 36 recovery contexts, 228 protected
journal-image refusals, direct proof/forgery/resource tests, twelve retained
typed/SQL saves with twelve empty follow-ons, and eight CLI saves/readbacks pass.
The shared preview kernel and earlier height-one/non-contracting paths pass their
focused regressions. Strict all-feature, minimal, journal-only and preview-only
build checks pass.

The large fixture retains 149,184 historical slots despite having 963 live rows.
Its CLI writes use explicit `--work-bytes 1000000000 --work-steps 1000000000`:
cumulative source/proof/recovery work exceeds the default byte allowance. The
initial budget refusal is retained in the
[execution record](../../testing/results/ace16-normal-recursive-retirement-writes-2026-11-01.json).
Defaults and expected images were unchanged.

Repeated retirement from a one-child original and all-descendant deletion remain
separate work. Their [eight source views](../../testing/results/ace16-repeated-retirement-new-text-key-sources-2026-11-01.json)
already pass read-only checks; source qualification does not enable mutation.
Nullable/DESC trees, arbitrary heights, nonempty root promotion and DATA-page
retirement remain outside this profile. Native Access save/reopen remains unrun.
